# 🐠 픽셀 아쿠아리움

가만히 켜 두고 보는 픽셀 힐링 수족관. *Placid Plastic Duck Simulator*에서 영감을 받았어요.

## 플레이
- **새 친구**: 오른쪽 위 게이지가 차면 물고기가 하늘에서 퐁당 떨어져요. 코인 15개로 바로 부를 수도 있어요.
- **합치기**: 같은 물고기를 끌어다 겹치면 한 단계 위 등급(일반 → 레어 → 에픽 → 전설)의 물고기가 랜덤으로 나와요.
- **먹이**: 물을 톡 치면 먹이가 떨어져요.
- **이름 짓기**: 물고기를 톡톡 두 번 누르세요.
- **코인**: 동전 물고기가 떨어뜨린 동전을 눌러 모아요.

## 물고기 사이의 사건들
- 🕵️ 도둑 물고기 → 저금통 복어에서 동전을 훔치고 → 오락기 물고기에 넣으면 띠리링♪ (잭팟도 있어요)
- 🐂 투우 물고기는 빨강이를 보면 돌진해요
- 🧲 N극·S극 물고기는 만나면 착 붙어요
- 🟥🟨🟦 젤리 셋이 합체하면…?
- 🌙 밤에는 아귀 초롱불, 디스코볼, 해파리가 빛나요 (게임 속 하루 = 16분)
- ☔🚢🦆🐋🌠🛸 비, 배, 오리 떼, 고래 그림자, 별똥별, 그리고 가끔 UFO

## 실행
`index.html` 하나로 돌아가요. 브라우저로 열면 끝. 진행 상황은 브라우저(localStorage)에 저장돼요.
