# 🐠 픽셀 아쿠아리움

가만히 켜 두고 보는 픽셀 힐링 수족관. *Placid Plastic Duck Simulator*의 오리 친구들을 물고기로 옮겨 왔어요.

## 플레이 (비둘기키우기 + 오리 시뮬레이터)
- **먹이 🍤**: 먹이는 시간이 지나면 차요. 먹이를 주면 새 친구가 와요.
- **합치기**: 똑같은 친구 둘을 끌어다 겹치면 다음 친구가 돼요. 일반 바다는 1~100단계, 한 단계에 한 종류예요.
- **코인**: 일반 바다 친구들이 가만히 있어도 코인을 벌어요. 뒤 단계일수록 많이 벌어요.
- **상점**: 어항 넓히기, 먹이 통, 먹이 충전, 먹이 업그레이드, 두 단계 점프, 자동 합치기, 자동 먹이, 코인 부스트
- **변종**: 합칠 때 가끔 튀어나오는 친구들(180종 이상). 만나면 보너스가 영구로 붙어요.
- **도감**: 만난 친구를 누르면 소개 카드를 다시 볼 수 있어요. 이름 짓기는 물고기를 톡톡 두 번!

## 물고기 사이의 사건들 (일부)
- 🐉 드래곤의 불 → 나무·체크무늬·종이 친구에게 불이 붙어요 → 🚒 소방관·광대·물총이 꺼 줘요
- 🕵️ 좀도둑 → 저금통에서 동전 슬쩍 → 오락기에 넣으면 띠리링♪ / 밤에는 너드가 변신!
- 🐂 황소는 빨간 친구를 보면 돌진, 🧲 양극·음극은 착, 🟥🟨🟦 슬라임 셋은 합체
- 🗡️ 뾰족한 친구 → 풍선은 펑, 피냐타는 와르르 / 🎂 케이크 촛불은 물이 닿으면 꺼지고 생일 축하 노래
- 🪆 마트료시카는 동생을 낳고, 🥷 닌자는 숨고, 🍎 사과의 애벌레는 나비가 돼요
- 🌙 밤에는 빛나는 친구들, ☔ 비, 🚢 배, 🦆 오리 떼, 🐋 고래, 🌠 별똥별, 🛸 UFO(젖소 조심)
- 🗝️ 칠판·낱말퍼즐·엽서·우유곽을 눌러 보면 비밀번호 힌트가…
